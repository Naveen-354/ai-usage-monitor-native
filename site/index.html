    A FEW GOOD QUESTIONS
    
        
    
          
    
            How do I install it?+
            
    
              Download the .exe from the latest GitHub release, put it in a
              permanent folder, and run it. Use the tray menu to quit. The app
              stores its data locally in your AppData folder.
            
    
          
    
          
    
            Does it show my subscription limit?+
            
    
              It shows token counters saved by your local coding agents. The
              Claude Code five-hour window is a local estimate, not a
              subscription percentage. Usage from other devices or websites is
              not included.
            
    
          
    
          
    
            Does it need my API keys?+
            
    
              Usage monitoring needs no API keys. It reads local usage records.
              Optional account management uses each agent’s own sign-in flow.
            
    
          
    
          
    
            Can I use it on macOS or Linux?+
            
    
              This release targets Windows 10 and 11. Other operating systems
              have not been validated yet. Source code and build instructions
              are available on GitHub.
