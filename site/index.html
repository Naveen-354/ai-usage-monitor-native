See what your AI coding agents are using.

A small floating overlay that counts the tokens used by Claude Code, Codex, Gemini CLI, Antigravity and OpenCode. It reads the files your agents already wrote to your own disk. Nothing is uploaded, and there is no telemetry.

What it does

Floating overlay

Always on top, draggable, remembers where you left it. Click to expand into per-agent totals.

Every agent in one place

Claude Code, Codex, Gemini CLI, Antigravity and OpenCode, side by side, with input, output and cached tokens.

Activity heat map

A year of daily usage in the style of a contribution graph, for all agents or one at a time.

Honest numbers

When an agent has no reliable data it says so. It never shows a zero it cannot stand behind.

Diagnostics

See what was found, what each collector read, and reload to find agents you installed since.

Tiny and native

One small executable. No browser engine, no background service, and a few tens of megabytes of memory.

Install

  1. Download the latest version with the button above.
  2. Run it. Windows may show a SmartScreen warning because the app is not code-signed yet: choose More info, then Run anyway. Verify the download first (below) if you want to be sure.
  3. Quit from the tray icon any time. Your data stays in %APPDATA%\dev.aiusage.monitor.native.

Files in

    Verify a download in PowerShell, and compare with the SHA-256 above:

    Get-FileHash .\<file> -Algorithm SHA256

    Privacy
    
      
    The app reads token counters, model names, timestamps and the folder name a session ran in. It never reads prompts, responses, code, or credential files, and it sends nothing anywhere. This page is a plain website: it loads no analytics, no fonts and no scripts from other sites.
    
      
    The full audit of what is read, per agent, is in PRIVACY.md.
